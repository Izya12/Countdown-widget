# Security

This is an unreleased application under development. It has no network backend and stores events locally. Do not publish personal backup files or signing keys in issues.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Izya12/Countdown-widget/security/advisories/new). Include the app version, Android version and minimal reproduction steps. Do not include real events, personal backups or signing material. There is no guaranteed response SLA. Ordinary bugs can be reported in the public issue tracker.

Release review includes manifest permissions/exported components, dependency advisories/licenses, migration safety and untrusted JSON validation. These reviews are not yet complete for v0.1.
