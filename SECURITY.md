# Security

This is an unreleased application under development. It has no network backend and stores events locally. Do not publish personal backup files or signing keys in issues.

A private vulnerability reporting channel must be configured before the first public release. No security contact or support SLA is currently advertised. Until one exists, do not post sensitive reports publicly.

Release review includes manifest permissions/exported components, dependency advisories/licenses, migration safety and untrusted JSON validation. These reviews are not yet complete for v0.1.
