# Круглый виджет 1×1

На рабочем столе откройте список виджетов → «Обратный отсчёт» → **«Круглый отсчёт 1×1»**. Перетащите его в одну ячейку, выберите событие и сохраните настройку.

- Белый круг, чёрное число и единица времени внутри; название события снизу.
- Вне круга фон прозрачный, название белое с тенью для разных обоев.
- Единицы выбираются отдельно для каждого экземпляра: «Как в событии», «Дни» или «Недели». Можно добавить одно событие дважды и показывать дни рядом с неделями. При выборе «Как в событии» формат «Недели» сохраняется, остальные форматы показывают дни.
- Прошедший срок отображается со знаком «+». Архивные/завершённые события показывают статус.
- Кольцо показывает оставшуюся долю времени; его цвет берётся из события. Кольцо можно отключить в настройке виджета.
- Нажатие открывает событие. Можно добавить несколько независимых экземпляров.

Провайдер объявляет targetCellWidth/Height=1 и минимальные размеры40dp. Фактический размер ячейки задаёт лаунчер; Android12+ использует targetCell, старые версии — минимальные размеры. Виджет сохраняет круглую форму при изменении пропорций и ограничивает размер передаваемого bitmap. Таймеров с обновлением каждую секунду нет.
