# Privacy / Конфиденциальность

Applies to Отсчёт / Countdown (`io.github.izya12.countdown`), version 0.1.0.
Updated: 2026-09-19.

## English

Countdown stores event titles, dates, notes, categories, reminder settings and
widget preferences locally on your Android device. It has no account system,
advertising, analytics, crash-reporting service or application server. The app
does not request Internet permission or transmit this information to the developer.

Notifications require your permission on supported Android versions. A reminder
may display an event title on your lock screen, depending on your Android settings.
The boot permission lets the app restore background scheduling after a restart.

Backup export writes event data to the location you select using Android's file
picker. A selected cloud storage provider may upload that file under its own policy.
JSON backups are not encrypted by this app; keep them in a trusted location.
Import reads only the backup file you explicitly select. Widget IDs and notification
delivery history are not included in exported backups.

You can delete events in the app. Clearing app storage or uninstalling removes its
local data; previously exported files must be deleted separately. Android's automatic
app backup and device-to-device app-data transfer are disabled for this app.

Support: https://github.com/Izya12/Countdown-widget/issues
Do not attach personal event databases or backups to public issues. GitHub and
F-Droid operate their websites and distribution services under their own policies.

## Русский

«Отсчёт» хранит названия событий, даты, заметки, категории, напоминания и настройки
виджетов локально на вашем Android-устройстве. В приложении нет аккаунтов, рекламы,
аналитики, службы отправки отчётов о сбоях или сервера. Приложение не запрашивает
разрешение на Интернет и не передаёт эти сведения разработчику.

На поддерживаемых версиях Android уведомления требуют вашего разрешения. Название
события может появиться в уведомлении на экране блокировки согласно настройкам Android.
Разрешение запуска после загрузки позволяет восстановить фоновое расписание.

Экспорт записывает данные событий в место, выбранное вами через системный выбор файла.
Если выбран облачный провайдер, он может загрузить файл в облако по своим правилам.
Приложение не шифрует JSON-копии: храните их в доверенном месте. Импорт читает только
выбранный вами файл. Идентификаторы виджетов и история доставки уведомлений в экспорт
не входят.

События можно удалить в приложении. Очистка хранилища или удаление приложения удаляет
локальные данные; ранее экспортированные файлы нужно удалить отдельно. Автоматическое
резервное копирование Android и перенос данных приложения между устройствами отключены.

Поддержка: https://github.com/Izya12/Countdown-widget/issues
Не прикладывайте личные базы событий и резервные копии к публичным обращениям.
Сайты и сервисы распространения GitHub и F-Droid действуют по собственным правилам.
